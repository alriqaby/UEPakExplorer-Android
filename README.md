## 📖 Overview

UEPak Explorer is an Android-native utility designed for working with **Unreal Engine PAK archives** directly on a mobile device.

It is useful for inspecting the contents and structure of PAK files, locating specific assets, exploring directories, and extracting selected files for further analysis.

The project is designed to be simple, fast, and independent of desktop environments.

## ✨ Features

| Feature | Description |
| --- | --- |
| 📦 **Open PAK** | Open and inspect Unreal Engine `.pak` archives directly on Android |
| 📂 **Browse** | Explore folders and complete internal file paths |
| 🔎 **Search** | Quickly find files inside PAK archives |
| ☑️ **Multi-select** | Select multiple files for batch operations |
| 📤 **Extract** | Extract selected files to your device |
| 🧩 **Asset inspection** | Work with common Unreal Engine assets and localization files |
| ⚡ **Native ARM64** | Built for ARM64 Android devices |
| 🔐 **No Root** | Works without root access |
| 🚫 **No external runtime** | No Windows, Winlator, .NET, or desktop runtime required |

## 📱 Requirements

- **Android 8.0 (API 26) or later**
- **ARM64** device recommended
- Root access is **not required**
- No Windows or Winlator required
- No external Java/.NET runtime required

## 🛠️ Installation

1. Download the APK from the official Releases page.
2. Install it on your Android device.
3. Open **UEPak Explorer**.
4. Select a `.pak` archive.
5. Browse, search, select, or extract files as needed.

> Android may ask you to allow installation from your browser or file manager when installing an APK downloaded outside Google Play.

## 🔍 What can it be used for?

UEPak Explorer is suitable for inspecting files commonly found inside Unreal Engine projects, including:

- `.uasset`
- `.uexp`
- `.ubulk`
- `.locres`
- `.ufont`
- Localization directories
- Font files
- Game assets and other files stored inside PAK archives

The application is intended as a **general-purpose Unreal Engine PAK exploration tool**, not as a tool tied to any particular game.
